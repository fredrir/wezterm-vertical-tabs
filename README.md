# wez-vertical-tabs (WiP)


## Installation

```sh
local vtabs = wezterm.plugin.require "https://github.com/fredrir/wez-vertical-tabs"
vtabs.apply_to_config(config, {
  width = 28,
})
```
> Apply the plugin after your own key bindings so its defaults can be overridden or disabled per binding.
