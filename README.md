# wezterm-vertical-tabs (WiP)

## Installation

```sh
git clone --branch native https://github.com/fredrir/wezterm-vertical-tabs.git
cd wezterm-vertical-tabs
cargo xtask deploy   # macOS: build, install and replace /Applications/WezTerm.app
cargo xtask install  # managed launch entry only
cargo xtask launch
```
